# Web i18n 规范

Web 国际化使用 `@intlify/unplugin-vue-i18n` + `vue-i18n` 实现，当前支持 `zh` 和 `en`。

## 一、资源归属

新增文案时，按以下顺序判断存放位置：

1. 仅在一个 Vue 页面或组件内使用：放在该 `.vue` 文件的 `<i18n lang="yaml">` 中。
2. 仅在一个 TS、TSX、hook 或 store 内使用：在该文件内定义 `messages`，并使用 `useScope: 'isolated'`。
3. 确实被多个文件共享，或必须在组件 setup 外解析：放在 `src/locales/*.json` 全局资源中。
4. `definePage` 的路由标题无法直接调用 `t`，使用全局资源配合 `i18nTitle`。

非 Vue 文件不等于全局场景。hooks、stores、TSX 中的专用文案仍应优先定义在各自文件中。

### 1. Vue 页面或组件

页面、布局和组件的专用文案优先使用局部资源：

```vue
<template>
  <p>{{ t('hello') }}</p>
</template>

<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>

<i18n lang="yaml">
zh:
  hello: 你好世界！
en:
  hello: Hello World!
</i18n>
```

局部 key 只在当前 Vue 文件中生效，不同文件允许使用相同 key。

### 2. TS、TSX、hooks 和 stores

专用消息与代码放在同一文件，并使用 `isolated` scope：

```ts
import { useI18n } from 'vue-i18n'
import type { LocaleMessages } from '@/utils/i18n'

const messages: LocaleMessages = {
  zh: {
    saved: '保存成功',
  },
  en: {
    saved: 'Saved',
  },
}

export const useSaveTip = () => {
  const { t } = useI18n({ useScope: 'isolated', messages })

  const showSaved = () => {
    window.$message.success(t('saved'))
  }

  return { showSaved }
}
```

`useI18n` 必须在组件 setup 执行期间调用。组合式函数应在 `<script setup>` 顶层调用，不要首次放到 `onMounted`、定时器或事件回调中执行。

### 3. 全局资源

全局资源存放在：

```text
apps/web/src/locales/zh.json
apps/web/src/locales/en.json
```

只允许存放以下内容：

- 至少被两个文件复用的公共文案。
- 路由标题等需要跨组件或在 setup 外解析的文案。
- 其他无法合理归属于单个页面、组件、hook、store 的消息。

禁止把单个页面、组件、hook 或 store 的专用文案放入全局资源。全局 JSON 必须使用至少二级命名空间：

```json
{
  "common": {
    "save": "保存"
  }
}
```

使用时通过 `t('common.save')` 获取。`zh.json` 与 `en.json` 的 key 必须保持一致。

## 二、路由标题

`definePage` 是编译期宏，不能直接调用组件内的 `t`。先在全局资源中定义标题：

```json
{
  "pageTitle": {
    "profile": "个人信息"
  }
}
```

页面中使用 `i18nTitle`：

```vue
<script setup lang="ts">
import { i18nTitle } from '@/utils/i18n-title'

definePage({
  meta: {
    title: i18nTitle('pageTitle.profile'),
  },
})
</script>
```

路由和布局通过 `resolveTitle` 解析 `$i18n.` 前缀，切换语言后会同步更新页面标题和浏览器标题。

## 三、语言切换

语言偏好统一由 `usePreferenceStore` 持久化，支持「跟随系统」：

```ts
const preferenceStore = usePreferenceStore()
// 'system' 跟随浏览器语言，也可直接指定 'zh' | 'en'
preferenceStore.setLanguage('en')
```

`useLocaleStore` 只保存解析后的生效语言，不再读写 localStorage；直接调用它只影响运行时，不会持久化：

```ts
const localeStore = useLocaleStore()
localeStore.setLocale('en')
```

`setLanguage` 会持久化偏好，并同步：

- `vue-i18n` 当前语言。
- Naive UI 组件及日期语言。
- HTML `lang` 属性。
- 路由和浏览器标题。

## 四、提交前检查

新增或修改国际化文案后确认：

1. 专用文案位于对应 Vue、TS、TSX、hook 或 store 文件内。
2. 只有真正共享或必须全局解析的文案进入 `src/locales`。
3. `zh` 与 `en` 的 key 一一对应。
4. TS、TSX、hook、store 的专用消息使用 `useScope: 'isolated'`。
5. 表单配置等需要随语言切换更新的数据使用 `computed`。
6. 执行 `bun lint` 和 `bun check`。
